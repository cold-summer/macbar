# 本地资产与事实

事实依据：本项目 main.m 与 README.md；不涉及外部产品版本或规格推断。

MacBar 图标：assets/AppIcon.svg（仓库原版），母题为冰蓝托盘收纳三个白色菜单项。原版冰蓝色 #72d5f6 / #439bdc，深蓝底 #103367。本轮按用户要求，仅将蓝色用于小面积交互或标识，所有背景保持浅色。暖白版本的青绿为探索提案，非已有品牌规范。

应用图标来自本机已安装 app 的 NSWorkspace 图标：Clash Verge、Lark、WeChat、ChatGPT、magpie。声音、用户、Wi-Fi、电池使用 macOS SF Symbols。所有导出图像位于 assets/，并打包为 icons.json 的 data URL，以便每个 HTML 独立打开。工具型界面无需额外照片或装饰插画。

数据说明：名称取自用户截图；5/3/1 分组属于概念演示，非当前用户配置。原型所有互动只影响当前页面内存，不修改应用配置、权限或系统图标。录屏默认为无需使用，不暗示已获得任何权限。
