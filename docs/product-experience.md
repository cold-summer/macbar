# 从使用者出发的设置流程

使用者打开 MacBar 是为了收好菜单栏图标，随后仍能认出应用、打开菜单、看到消息提示。设置页需要回答“能不能用”“新应用会怎样”“未读提示能否跟随顶部”，而不是要求使用者先理解窗口捕获接口、缓存或权限类别。

## 首次使用

辅助功能是整理图标的必要条件，因此在列表上方始终显示系统真实状态。已授权用绿色“已开启”，未授权用“先开启才能用”，并提供前往系统设置的按钮。未授权时保留顶部图标展开，位置控件禁用。首次启动没有辅助功能权限时自动展示设置页。

图标显示采用结果导向的两个选项。“标准图标”直接显示应用图标，不需要录屏；说明其不包含菜单栏里的未读数字。“与顶部一致”读取对应菜单栏窗口的画面，可保留同一窗口内的数字、文字与颜色。首次选择且未授权时，先解释系统将这项权限称为“录屏”、授权对象是 MacBar、不会保存截图或录制视频，再由使用者前往系统设置。取消时恢复标准图标。已有权限时切换即可使用。

## 安装或启动新应用

全局选择“新图标放到：收集栏／顶部菜单栏”，仅影响之后首次发现的第三方应用图标。已有位置和顺序不受影响；系统图标仍默认留在顶部。新应用启动并创建菜单栏图标后自动发现、分类和显示，不要求再次为每个应用授权或手工截图。只有 Dock 图标的应用不会加入。标准图标和顶部同步都遵循这项自动发现规则，不维护应用白名单。

## 日常使用和失败恢复

只读取打开的收集栏实际需要显示的图标窗口，关闭后停止读取。同步约每三秒刷新，不等于即时消息订阅，也不自行生成未读数。窗口读取失败时可保留上次有效画面，设置页显示同步状态，悬停相应图标说明它使用上次画面或标准图标。收集栏不增加常驻文字和额外高度，保持紧凑。下次成功读取自动清除旧画面标记。顶部和不显示的图标不为收集栏额外读取。

录屏已授权与正在同步是两个独立状态。标准模式下即使已有授权，也不读取画面。系统权限状态保持可见，帮助入口解释一次设置与自动发现的关系。

## 验证

回归测试覆盖未知应用自动加入、新默认位置不影响既有配置、后续应用沿用全局同步且不再次请求权限、未授权和关闭收集栏时不读取、只读取收集栏项目、动态文字宽度保留、失败标记和恢复清除。原生 AppKit 预览覆盖两种显示模式与两种权限的八种组合、筛选、窗口缩放、空列表以及首次同步说明的继续／取消流程。

真实飞书新消息的未读数字尚未完成实测。数字属于独立叠加窗口或应用离屏后不更新时，不能保证同步；界面和文档不应承诺所有应用实时一致。

可重复运行：`./scripts/test.sh` 验证 129 条行为断言，`./scripts/test-ui.sh` 在本机桌面验证模拟权限流程并输出原生设置截图。另在 macOS 14.6、Apple Silicon 上操作已安装应用，验证帮助说明、实际收集栏筛选、打开收集栏和返回设置；默认模式诊断显示已具备录屏权限但捕获调用仍为 0。
