# 兼容性与验证范围

MacBar 当前是预览软件。最低部署目标为 macOS 14.0，构建支持 Apple Silicon 和 Intel；包含相应架构不等于已在每种硬件上完成实机验收。

## 已有验证

| 范围 | 验证方式 | 边界 |
| --- | --- | --- |
| 身份与偏好 | 模拟窗口、AX 描述及独立偏好域的回归测试 | 不使用坐标、宽度或动态标题作为持久身份 |
| 点击和恢复 | 模拟单次 down/up、菜单观察、失败和重试；部分原生面板实机操作 | 事件回执不能证明目标界面已打开 |
| 图标原样与明暗 | 图像单元测试、离屏窗口内部抓取 | 本机曾取到 12/12 收集栏图像；不代表任意应用均可读取 |
| 多显示器 | 双屏问题复现修正、负坐标与窗口副本测试 | 所有物理排列、全屏及自动隐藏组合尚未逐项实测 |
| 不显示与恢复 | 偏好回归测试及部分实机配置操作 | 系统拒绝移动时保留设置并提示 |
| 通用点击规则 | 未知应用包、运行类型及元数据测试；运行中应用分类诊断 | 2.5.0 的所有应用主窗口尚未逐一完成 GUI 验收 |
| 构建 | 本机测试与 universal 编译；GitHub CI | CI 不授予真实用户权限，也不做完整桌面交互测试 |

## 已知限制

- 跨进程菜单栏移动依赖系统事件和动态加载的私有窗口接口，系统升级可能改变行为。
- 有些系统图标无法移动或无法隐藏；MacBar 不保证绕过这些限制。
- 某些应用在不同显示器上没有有效的可操作副本。MacBar 不会用同进程的未知图标替代目标。
- 同进程多个图标不能获得稳定身份时，会保留在顶部，不猜测对应关系。
- 一些原生界面由其他进程绘制，或没有可观察的弹出窗口，菜单关闭检测可能需要进一步兼容。
- 普通应用左键使用系统重新打开请求，具体显示哪个窗口由应用自己处理。声明为 agent 的应用即使有主窗口，也可能继续走原生左键。
- 原样捕获失败时保留上次有效画面，失败期间的动态文字可能不更新。
- 收集栏会按屏幕可用宽度换行，没有专门的滚动或分页机制；极多图标的可用性仍需改进。
- 当前不提供登录时自动启动设置、自动更新、全局快捷键或英文界面。
- 发布包未通过 Apple 公证，首次打开及升级后授权可能需要用户处理。

遇到问题，请按 [故障排查](troubleshooting.md) 收集最少必要的信息，并通过 Issue 模板反馈。
